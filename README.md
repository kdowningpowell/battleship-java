# Battleship Game (Java)

This project is a console-based implementation of the classic Battleship game written in Java.

## Features
- Player vs Computer gameplay
- Ship placement validation
- Hit and miss tracking
- Win condition detection
- Random computer ship placement

## Technologies
- Java
- Object-Oriented Programming

## Files
- Battleship.java – Main game logic
- Grid.java – Game board management
- Player.java – Player actions and ships
- Ship.java – Ship object model
- Location.java – Individual grid cell logic
- Randomizer.java – Random number utilities
- ConsoleProgram.java – Console helper class
